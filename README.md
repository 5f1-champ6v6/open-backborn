# open-backborn
OPEN BACKBORNの開発・実験記録
OPEN BACKBORN は、ギターの「本体」という概念を分解し、ネックを中心とした“背骨”に、音響箱・ピックアップ・電子回路などを組み合わせていく実験的なモジュラーギター・プロジェクトです。
一般的なギターは、ネックとボディと電子回路が一体となった完成品として設計されています。
OPEN BACKBORNでは、それをあえて分解します。
ネックを「背骨」として独立させ、その周囲に取り付ける音響箱（Sound Box）や各種ユニットを交換可能にすることで、

* 音響箱を変えたら音はどう変わるのか
* 同じネック・同じ弦でも、構造を変えるとどこまで音が変わるのか
* ピックアップそのものを自由に交換・再構成したらどうなるのか
* エレキギターとアコースティックギターの境界はどこにあるのか
* 「良いギター」とは、そもそも何によって決まるのか

といったことを、実際に作りながら検証していきます。

現在の基本構想では、25.5インチスケールのネックを中心に、交換可能な音響箱を組み合わせる構造を検討しています。

素材や製法についても固定せず、木材、金属、樹脂、積層材、3Dプリントなど、目的に応じて自由に試します。
また、通常のギターピックアップだけに限定せず、リレーを利用したピックアップなど、既存の「ギターパーツ」の枠から外れた方式も実験対象とします。
OPEN BACKBORNは、最初から完成形を決めて作るプロジェクトではありません。

作る → 弾く → 壊す → 考える → また作る。

その過程そのものを記録しながら、ギターという楽器を別の角度から再構築していきます。
